# Nuffle Arena — collection par équipe

31 thèmes basés sur les rosters présents dans le catalogue Nuffle Arena consulté le 29 septembre 2026, dont les Bretonniens et les Slanns.
155 faces distinctes, chacune en PNG RGBA carré de 320, 128 et 64 pixels : 465 fichiers de faces.

## Organisation
`equipes/<identifiant-local>/<taille>px/<resultat>.png`
Les identifiants sont propres à ce pack ; ce ne sont pas des clés garanties de la base de données du site.
`manifest.json` : correspondance noms français, fichiers et palettes de conception.
`apercus/` : vue générale + 4 planches détaillées.

## Résultats
- attacker-down : attaquant plaqué, casque brisé.
- both-down : les deux plaqués, poings opposés.
- push : repoussé, paume.
- defender-stumbles : défenseur bousculé, bouclier incliné brisé.
- defender-down : défenseur plaqué, poing sur impact.

Pour les six faces d'un dé, utiliser deux fois push et une fois chacun des quatre autres résultats.

## Utilisation
Les PNG contiennent le symbole et sa face décorée. Les coins extérieurs sont transparents.
Les cinq signes conservent le même sens dans tous les thèmes. Les contours générés et les dimensions internes peuvent varier légèrement d'une série à l'autre.
Les palettes sont des choix créatifs pour ce pack, pas des couleurs officielles imposées aux équipes. Les valeurs de palette du manifest décrivent la direction graphique ; les pixels peuvent différer légèrement.
Le thème Skavens reprend orange, acier et bleu nuit.
Images matricielles, aucun faux fichier SVG contenant une image PNG.
