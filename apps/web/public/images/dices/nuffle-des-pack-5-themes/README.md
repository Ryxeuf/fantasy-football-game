# Nuffle Arena — Dés de blocage

5 résultats × 5 thèmes. Chaque face est un PNG RGBA carré ; les coins extérieurs sont transparents.
Trois tailles : 320 px (grand affichage), 128 px et 64 px (interface).
Les cinq symboles sont conservés dans toutes les déclinaisons ; les contours issus de générations différentes peuvent varier légèrement.

## Fichiers
- attacker-down.png : attaquant plaqué — casque brisé.
- both-down.png : les deux plaqués — poings en collision.
- push.png : repoussé — paume ouverte.
- defender-stumbles.png : défenseur bousculé — bouclier brisé incliné.
- defender-down.png : défenseur plaqué — poing et impact.

## Thèmes
- original-or : or et charbon, proposition validée.
- acier-bleu : argent, marine et contour bleu.
- chaos-rouge : ivoire, bordeaux et pointes rouges.
- malepierre : vert acide, vert sombre et losanges.
- glace : bleu marine, glace pâle et angles cyan.

Les illustrations sont en PNG, pas en SVG. Les fichiers contiennent la face carrée et son symbole, pas seulement le symbole détouré.
Les planches de conception ne sont pas requises pour l'intégration.

## Dé à six faces
Utiliser push deux fois ; chacun des quatre autres résultats une fois.
Le manifest.json fournit les libellés, les chemins 320 px et cette répartition.
